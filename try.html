② 演示项目4 篇文献 + 4 节示例正文（含引用、公式、表格），专门用来试新功能

  1. 文献导入导出（Zotero / EndNote / NoteExpress）：先下载示例文件，在「② 文献获取与管理」点「📥 导入 Zotero / BibTeX / RIS」，把文件拖进去。sample.bib 里有一条和演示项目重复，可以看到查重和「补全空缺字段」（会补上 DOI）。同一栏还能导出 BibTeX / RIS / CSL-JSON，或复制 GB/T 7714。
    ⤓ sample.bib⤓ sample.ris⤓ sample-csl.json打开 ② 文献库 →
  2. PDF 阅读、高亮批注：下载示例 PDF（内容是虚构的），在文献表第 4 篇的「全文」列点「📎 上传 PDF」。选中文字选颜色即可高亮，点「📝 批注」写笔记，「⤓ 批注 .md」导出。配好 AI Key 后可以试「✨ AI 精读」，看它给每条结论标页码。
    ⤓ demo-paper.pdf打开 ② 文献库 →
  3. Markdown / LaTeX / Word 导出：在「④ 设计与写作」点「⤓ Markdown」「⤓ LaTeX（Overleaf）」或「⤓ 导出全文 + 归属说明」。LaTeX 文件上传到 Overleaf，菜单 Compiler 选 XeLaTeX 就能编译，正文的 [n] 会变成 \cite。
    打开 ④ 写作与导出 →Overleaf ↗
  4. 本地同步（电脑上的 Chrome / Edge）：工作台左侧点「🔄 开启本地同步…」选一个位置保存 yanmo-sync.json。之后随便改点内容，约 3 秒后文件就更新了；可以放在网盘目录里。
    打开工作台 →
  5. 项目导图：看文献、正文、版本怎样连成一张图，点节点可以直接改写、存版本。
    打开演示项目的导图 →
  6. MCP（Claude Desktop / Cursor 等）：用第 4 步的同步文件，让 AI 客户端读取你的项目、文献和批注（只读）。
    README 里的配置说明 ↗

演示项目可以随时在工作台左侧删除；重新点上面的按钮会把它恢复成初始状态。文献 1–3 是真实论文，第 4 篇和示例 PDF 是虚构的，只用于测试。
